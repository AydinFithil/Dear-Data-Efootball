# Dear-Data-Efootball
Note: I started collecting this data on 05/10/2026 in a spreadsheet. I created this public GitHub repository on 19/10/2026, so the GitHub commit dates show when I uploaded my work, not when I collected the data.

## What am I collecting data about?
I am collecting data about the eFootball matches I play on my phone. My main question is: do my eFootball results change my mood?

## What am I recording about each match? (the content of each record)
Each row in my spreadsheet is one match. For every match I record:
- Match number
- Date
- Start time
- Game mode (for example online match or AI event)
- Goals for (the goals I scored)
- Goals against (the goals I conceded)
- Result (win, draw or loss)
- Mood after the match, scored from 1 (low) to 5 (high)

## My progress
I have collected 100 of my target of 100 matches. I started collecting on 5 October 2026 and recorded each match straight after playing it.
